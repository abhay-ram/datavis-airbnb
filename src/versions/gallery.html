London · Airbnb · Embed-Kit

Sieben Visualisierungen – eine Datei pro Variante

Drei Karten-Varianten, drei reine Balken-/Linien-Varianten und ein Streudiagramm, das die Airbnb-Daten mit der amtlichen Demografie verknüpft. Jede Datei ist eigenständig: keine Bibliothek, kein CDN, keine Server-Abhängigkeit – nur eine HTML-Datei, die sich per iframe überall einbetten lässt, auch in Pageflow.

33 Bezirke 3 Stichtage Jahr-Filter Bezirk-Hervorhebung Scroll-Animationen verknüpft mit ONS-Demografie DSGVO-freundlich: keine externen Requests

A Die sechs Varianten

B In Pageflow einbetten

1 · Dateien erreichbar machen

Pageflow bettet Inhalte über eine URL ein – ein lokaler Dateipfad genügt nicht. Laden Sie den Ordner dist/ unverändert hoch: zu GitHub Pages, zu Netlify Drop (Ordner einfach ins Browserfenster ziehen) oder auf einen eigenen Webspace. Danach hat jede Variante eine Adresse wie https://ihre-domain.de/1-linien-nach-bezirk.html.

2 · iframe-Element anlegen

Im Pageflow-Editor + → iframe embed wählen, die URL eintragen und die Option Dynamic Height aktivieren. Die Dateien senden das dafür nötige iframe.resize-Signal bereits mit – die Höhe passt sich also automatisch an, auch wenn sich Diagramm oder Text ändern.

Ohne Dynamic Height einfach ein Seitenverhältnis wählen: die Stories passen in 16:9, die Diagramme und Karten in 4:3 oder 1:1.

3 · Diese URL in Pageflow eintragen

https://ihre-domain.de/1-linien-nach-bezirk.html?embed=1

?embed=1 schaltet den kompakten Einbettungsmodus ein. Bei den beiden Scroll-Stories wird daraus automatisch ein Player mit Weiter-/Zurück-Buttons und Tastatursteuerung – so bleibt die Geschichte auch im iframe erzählbar.

E Steuerung aus der Host-Seite

    

      Die eingebettete Seite hört auf postMessage. Damit lässt sich die
      Visualisierung auch aus Pageflow, einem CMS oder einer eigenen Seite heraus steuern –
      etwa über eigene Schaltflächen oder einen Jahresumschalter im Artikeltext.
    

    

      
const frame = document.querySelector('iframe');
frame.contentWindow.postMessage({ type: 'year', years: [2026] }, '*');
frame.contentWindow.postMessage({ type: 'metric', metric: 'per1k' }, '*');
frame.contentWindow.postMessage({ type: 'focus', codes: ['E09000033'] }, '*');
frame.contentWindow.postMessage({ type: 'step', index: 3 }, '*');   // Stories
frame.contentWindow.postMessage({ type: 'theme', theme: 'dark' }, '*');

      
    

    

      Umgekehrt meldet jede Datei ihre Höhe per postMessage – sowohl im
      Pageflow-Format ({context:"iframe.resize"}) als auch als eigenes Objekt mit
      type:"height".
